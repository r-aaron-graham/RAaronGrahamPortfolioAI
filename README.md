agent governance, local AI, and infrastructure modeling.

## Preview locally

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/ from a browser. Start with Featured Projects for
the source repositories and AMIE browser demo.
